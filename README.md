## ✨ Características Principales

- 📊 **Gestión Avanzada de Datasets** - Sube, organiza y clasifica datos agrícolas fácilmente
- 🔐 **Autenticación Segura** - Sistema de login robusto con JWT
- 📸 **Procesamiento de Imágenes** - Extrae metadatos EXIF de imágenes agrícolas
- 📁 **Compresión y Exportación** - Descarga datos en múltiples formatos
- 🎨 **Interfaz Moderna** - Diseño responsivo con Angular y Tailwind CSS
- ⚡ **API RESTful** - Backend escalable con NestJS

## 🚀 Stack Tecnológico

### Frontend
- **Framework:** Angular 18.2
- **Estilos:** Tailwind CSS
- **Validación:** SweetAlert2
- **Lenguaje:** TypeScript (57.8%)

### Backend
- **Framework:** NestJS 11.0
- **Base de Datos:** MongoDB con Mongoose
- **Autenticación:** JWT + Passport
- **Procesamiento:** CSV Parser, EXIF Reader, Archiver

### Herramientas
- TypeScript 5.7
- ESLint + Prettier
- Jest para testing
- Soporte CORS y compresión

## 📋 Requisitos Previos

- Node.js 18+ 
- npm o yarn
- MongoDB en ejecución (local o remota)
